read the skill before authoring proposals. Otherwise read the public skill and use

confidence, applicability and rationale. Code validates, packages and reads exact
scientifically accepted outputs. Evidence review and software approval are not

explicitly replaced through an authorised contract; new T6E is outside this workflow.
