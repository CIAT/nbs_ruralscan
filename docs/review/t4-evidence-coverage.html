Why evidence was missed

QA reviewed extracted records, but did not reconcile every paper or every table class. Chuma’s approved numeric fields fell through an unsupported encoding; Haile’s table continued onto another page; Ahmad’s weights were image-only. Five shared PDFs never reached the source register.

New CI checks reconcile source coverage, inventoried class counts, live approval boundaries, exact reviewer follow-up notes and figure checksums. Compiler tests reject incompatible or overlapping table fragments. These checks protect documented coverage; they cannot prove an unseen PDF contains no further evidence.
