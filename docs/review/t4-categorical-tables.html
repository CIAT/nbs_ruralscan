Agroforestry: suitability rules (T4)

How to read this: agroforestry is the overall solution. A family groups practices with similar establishment needs (for example, planted silvoarable includes alley cropping and tree intercropping). Each row below describes one variable and how it affects that family.

Numeric rules describe rainfall, temperature, soils or slope. Host conditions check that suitable existing farmland, pasture or crops are present. A passed host condition does not establish overall suitability. Scores express relative source ranks: 1 is the highest rank, 0 means explicitly unsuitable. They are not probabilities; unknown means the evidence or input does not determine an answer.

7 numeric suitability rows · 7 host conditions · 1 retained legal exclusion · 8 investment scenarios. Shared evidence remains separate until family applicability is assigned.

Click headings to sort. Type under headings to filter. Open “Source rules and explanation” within a row for numeric bands, source context and input data.

Singh 2026 · Soil texture / Hydrologic Soil Group: Fine/fine-to-coarse/coarse source classes do not define HSG A-D or a calibrated score.

Cgspace singh southasia 2020 · Soil texture / Hydrologic Soil Group: Classes 1-7 described as soil quality; cannot treat them as soil texture/HSG codes.

Cgspace singh southasia 2020 · Land cover / land use class: Same class 1-4 versus 5-7 quote assigned to soil-quality and land-cover records; no independent land-cover legend established.

Ahmad 2018 · Tree canopy cover: Variable mismatch quote is ndvi not canopy cover

Scenario parameter grids still need a parameter choice. Site observations, study weights and mapped-area percentages are retained in the audit; they cannot define numeric suitability responses.
