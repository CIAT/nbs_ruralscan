Agroforestry: suitability rules (T4)

How to read this: agroforestry is the overall solution. An agroforestry system groups practices with similar establishment needs (for example, planted silvoarable includes alley cropping and tree intercropping). Each row below describes one variable and how it affects that system.

Numeric rules describe rainfall, temperature, soils or slope. Host conditions check that suitable existing farmland, pasture or crops are present. A passed host condition does not establish overall suitability. Scores use a common class convention: low 0.25, moderate 0.50, high 0.75, very high 0.90; 0 means explicitly unsuitable. A highest-ranked class is not automatically an optimum of 1. They are not probabilities; unknown means the evidence or input does not determine an answer.

FMNR rainfall — retained evidence, no defensible numeric cutoff

Previous 300–800 mm range combined study domains with suitability limits. WRI reports greatest observed spread at 400–800 mm and explicitly permits regreening below 400 mm. Chomba review reports adoption contexts of 100–950 mm and says suitability elsewhere remains uncertain. These are retained observations, not an upper exclusion or an optimum. Rainfall remains a candidate variable; no numeric FMNR response is currently justified by these records.

Scenario parameter grids still need a parameter choice. Site observations, study weights and mapped-area percentages are retained in the audit; they cannot define numeric suitability responses.
