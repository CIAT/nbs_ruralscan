How to read this table and its inputs

T4 is the rule table. Categorical rows expand into dataset codes; continuous rows specify numeric responses. Dataset bindings tell the runtime which data and bands supply the inputs. These are different views of the same configuration, not alternative versions of T4.

Host gates require aligned datasets and additional masks. Shaded crops combine by OR while retaining crop fractions. Linear placement requires boundaries and a locally justified width. Silvopasture requires GPW grassland plus local grazing confirmation.
