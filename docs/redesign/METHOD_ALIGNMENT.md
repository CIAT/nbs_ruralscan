## Boundaries still visible

Threshold numbers and map surfaces are synthetic. The current classification catalogue contains no accepted runtime rules. Tercile preview has no supported no-problem condition, so only Low/Medium/High are emitted. A future real rule needs native units, valid domain, justified none condition where applicable, scientific acceptance and context-compatible data. The saved reference hash proves bytes, not scientific validity.

The six-stage calculation explanation is current, but the geographic mock-up does not execute that pipeline. The two-concern arithmetic example is isolated from the maps. Presets illustrate preference entry only. Current practice definitions and evidence counts have one home in the Methodology; no private review state or live write route is introduced here.
