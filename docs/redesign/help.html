Explore the method. Help shape it.

This visual methodology presents an idealised implementation through a wireframe and mock-up. It gives the Alliance and the World Bank a tangible basis for discussion, design and aligning expectations.

This is not a tool the Alliance is building under its contract. The contracted outputs are the methodology toolkit, pilot implementation report and reproducible Jupyter/Colab notebooks. Displayed examples are not pilot results.

Help with the walkthrough

Where should I start?

Start with Setup, then follow the seven stages. The home-page overview explains what each stage contributes. This is a scoping method; site feasibility and detailed design follow separately.

How do I review variable distributions?

In 3.2 People and land or 3.3 Livelihood risk, select C.5 beneath a map. Review the variable, direction, class count and cut points beside its distribution. Valid edits update the maps and summaries. Apply default values restores the selected variable’s defaults.

Use the class checkboxes and Table / Plot toggle to explore summaries. People/land summaries compare area shares; livelihood-risk summaries compare population shares across baseline and future conditions.

Are the maps and results real?

The walkthrough uses synthetic example data on real Sierra Leone boundaries. It illustrates the method and intended interactions; it does not run a live spatial analysis or provide investment recommendations.

How do I give feedback?

Use Review mode in the version bar to annotate the page and export your notes. Include the stage or figure number, what you expected and what needs changing. Review notes stay in your browser until you choose to share them. You can also contact the project team below.

Are settings saved or shared?

Demonstrator settings are stored in your browser. Use C.6 Save and load to export or reopen settings. They are not a shared project database. Some export links remain illustrative placeholders.
