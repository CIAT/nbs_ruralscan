Rural NbS Scan · method demonstrator

Where could nature-based solutions pay off for rural people?

Task teams have to scope an investment long before a feasibility study: where each nature-based solution could work, who lives there, and what the evidence says it does. This scan answers those three questions at country scale, for World Bank task team leaders and their counterparts.

You leave with four scoping-grade products:

  • An opportunity mapwhere each practice could establish
  • A hotspot shortlistwhere that overlaps the project’s priorities
  • A practice comparisonfootprint, evidence and indicative cost
  • A draft scoping briefwhat to check next, and with whom

1.1Six stages, always in this order

Each stage answers one question and hands its result to the next.

  1. 01Set the scopeWhat problem, which practices, where?
  2. 02Map the opportunity spaceWhere could the practice establish?
  3. 03Screen project riskWould hazards put the planting at risk?
  4. 04Find priority hotspotsWhere does it meet the project’s priorities?
  5. 05Compare practicesWhich practices deserve a closer look?
  6. 06Plan next stepsWhat must feasibility confirm?

1.2What this is

Scoping
A first, country-scale view of where to look, before anyone visits a site.
A method demonstrator
Shows how the stages fit together so the team can agree the method.
Example data
Maps use an authored surface that behaves like real inputs.

1.3What it is not

Feasibility
No site design, cost–benefit analysis or ecosystem-service model. Those follow.
The final interface
The contracted delivery is a set of reproducible notebooks.
A pilot result
No figure on these pages describes Sierra Leone.

1.5Technical configuration

Two separate things, both optional, both kept out of the walkthrough:

Choosing datasets
Which source represents each variable — for example a national soil map instead of a global one. Rules stay the same.
Tuning rules
How a variable becomes suitability. Rules come from the evidence register, and any edit is logged.
