What sits underneath the walkthrough?

The datasets, rules, masks and settings every map is built from. The walkthrough never needs this page; it is here so an analyst can check, propose a change, or save the set-up.

C.1Input datasets

Do you need this? Only if a country dataset should replace a global default.

Choosing datasets changes which source represents a variable — for example a national soil map in place of a global one. The rule that turns the variable into suitability stays fixed. A change is recorded as a proposal first and applied only after a compatibility check.

C.2Suitability functions

Do you need this? Only to check or question how a variable becomes suitability.

Tuning rules changes the response curve or threshold for a variable — how slope or rainfall becomes a suitability score. The dataset behind it stays fixed. Edits are recorded against the example recipe and downstream results stay the unchanged example.

C.4Correlation and clustering

Do you need this? Only to see why some variables are not used directly.

Download PNG

Figure C.2 · Example correlation matrix and clusters for six variables in the area of interest; the representative of each cluster is underlined

Why one per cluster. Variables that move together carry the same signal. Using all of them would count that signal several times and quietly raise its weight.

How it works. Variables are first grouped by theme in the recipe, then clustered by correlation within the area of interest. One representative per cluster enters the score; the other members stay listed beside it.

In this example precipitation represents soil moisture and greenness (NDVI); temperature represents elevation; slope stands alone. Correlations are example values.

C.5Climate

Do you need this? Only to change the climate scenario or the risk framing.

Risk framing

Double counting. Mode B adds vulnerability. The same vulnerability variables (poverty, food insecurity) already appear in the hotspot priorities in Stage 05, so using both counts them twice. Keep Mode A unless the hotspot priorities drop them.
