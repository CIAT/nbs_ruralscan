Study use, relative importance and support for a calibrated function are different measures. Weight summaries cover reconstructed weight models, not every evidence source; other reported weights may remain uncompiled. Missing weights mean unknown, not zero. Regional and FMNR practitioner models are not pooled. No aggregate below becomes a runtime weight.

How to read the aggregation

Use counts come from explicitly verified model-use records, deduplicated by reporting paper. Denominator is the recorded model-use cohort, not all papers in the library; absence is unknown. All recorded includes unreviewed inputs. Group use counts a paper once across its variables.

Relative importance is the source hierarchy-adjusted ratio to equal weighting: 1× means equal-share benchmark, above 1× means higher source-model importance. Whole-model shares retain the original model denominator, including operational criteria. For each scope, alternative models are first summarized within source; medians/ranges then describe reporting sources, not independent replicates. Different regions and variable sets limit comparison.

Group weight cells show mapped-group sums per original model. Where some raw variables lack an unambiguous ontology mapping, these sums are partial and explicitly labelled; they are not the original declared group weights. No residual is redistributed.

Directional counts cover explicit increasing/decreasing/optimum/nonmonotonic fields only; qualitative prose and coded classes remain in source evidence. Function counts are distinct source IDs per existing mapping, not option counts or global validation.
