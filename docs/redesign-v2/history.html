H.1From v0 to v2

v0 · July 2026

Original mock-up

The first published mock-up: one page with six stage tabs, from Setup to Next steps, plus developer tabs. It fixed the order of the stages and the content each one carries — suitability, project risk, priority hotspots, practice comparison — and its link to the schema tables. Each tab was a grid of equal panels with toggles, chips and charts, and the maps used radial gradients with per-cell noise. Open v0

v1 · October 2026

Draft revision

A revision after the World Bank session of 6 October and the team’s comments. It put project background before settings, opened maps as district summaries, replaced the overall risk score with separate hazard overlays, and added the five Scorecard indicators, a budget box, local save and load, and scripted AI examples. It was not taken forward: the example map repeated twelve authored values in visible blocks, the opening still read as a form, and each stage remained a set of equal panels. The project lead rejected the maps and the landing page on 28–31 October. Open v1

v2 · November 2026

This redesign

Built from a diagnosis of five failures shared by v0 and v1: example data that looked authored, page furniture before content, no single question per stage, abbreviation-heavy labelling, and caveats repeated as content. Each stage now asks one question, shows one main figure and keeps depth in numbered sub-tabs. A visible control bar holds practice, suitability classes, view and climate. The example surface is one coherent synthetic field on real Sierra Leone boundaries. Stage 02, Explore the practices, was added, and technical configuration became its own page. Open v2

Unchanged throughout

What has stayed the same

The scan scopes; it does not assess feasibility. The contracted delivery is a set of reproducible notebooks, and these pages demonstrate the method. No figure in any version is a pilot result.
