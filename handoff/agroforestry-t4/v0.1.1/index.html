Agroforestry T4 — first pass v0.1.1

10 numeric rows · 7 host gates · 1 hard exclusion. 8 operational scenarios kept separate. Configuration ready for inspection; field applicability and pilot execution remain to validate.

Hierarchy: suitability theme → variable group → canonical measurement → dataset. Aliases stay in variables.csv. Related proxies remain separate until context-specific selection; dataset resolution alone does not establish quality. Source importance stays separate from runtime weights.

Remaining limitations and required inputs

Numeric rows retain regional source profiles; they are not universal pooled curves. FMNR rainfall remains contextual evidence, without an executable rainfall cutoff. Soil pH/source boundary conflicts remain held. Local inputs: farmland_context, field_boundary_zone, grazing_system_present, managed_forage_without_grazing. Recipe/BIND differences: annual_precipitation, mean_annual_temperature. Read dataset notes before execution. No pilot run performed.

How to read curves, weights and practice names

Plots show retained source bands on the common suitability scale, not automatic runtime curves. Open circles exclude endpoints; filled circles include them. Arrows mark unbounded reported tails clipped to the plotting window. Empty regions have no plotted score; overlapping segments remain unresolved. No interpolation is added. A row with a separate default threshold retains that default until a source response is selected.

Numeric defaults are equal (0.2 in current T4). Masks are gates, not weighted votes. Relative importance ratios compare each variable with its study's equal-importance reference; 1 means equal, 2 means twice that reference. Full study denominators and alternative models remain separate. These ratios are not adopted runtime weights.

Standard vocabulary: Agroforestry (NbS) → suitability system → practice. Practice membership shown here is registry membership, not proof every source applies to every listed practice. Unassigned evidence is not automatically planted silvoarable. Haile parklands may be planted or regenerated; Chuma is regional; Ahmad NDVI describes mixed systems. Any planted-system assumption must be a separate sensitivity scenario, preserving original classification.

Rule and sources

Evidence-backed categorical gate. Castle Table 2 (PDF p8) defines alley cropping on annual cropland or forage grown between tree rows without grazing, excluding existing tree crops. WorldCover 40 maps annual cropland. WorldCover 30 is conditional on a verified managed-forage/non-grazing mask; it is not treated as pasture proof. Land cover / land use classCategorical host gate
Rule and sources

Evidence-backed categorical gate. WOCAT 507 describes restoring degraded wasteland and improving depleted farmland (Kenya example, PDF p1). Within the regeneration-on-farmland family, WorldCover alone cannot identify degradation or farmland history. Positive classes require observed depleted/degraded farmland masks; bare soil alone is never evidence of restoration potential. This gate establishes land-use compatibility, not regeneration success or rootstock presence. Tree cover remains unresolved. Pete input review 2026-10-20: depletion/degradation are targeting context; non-cropland requires farmland identity.

Rule and sources

Candidate applicability gate for windbreaks/shelterbelts only. Castle Table 2 PDF p8 places windbreaks on delineated cropland/pasture field boundaries in the US Midwest. WorldCover cropland requires independently mapped field-boundary placement; grassland additionally requires managed pasture confirmation. No universal buffer width or contour-siting rule is inferred.
