# Agroforestry T4 v0.1.5 — clearer study counts

[Open table](index.html) · [Readable CSV](T4_review.csv)

The table now separates:

- **Studies using variable group:** papers with recorded use of any group member, divided by the eligible model-study cohort.
- **Studies using variable:** papers with recorded use of this variable, divided by that cohort. This percentage is not review completion.
- **Review status:** how many of those variable-using studies have at least one approved record of variable use. It does not mean every extract from each paper is approved.
- **Studies supplying numeric rules:** distinct reporting papers with numeric profiles in this specific T4 row. A paper can use a variable without supplying a usable response curve.

For NDVI: 3/10 studies use it (30%); all three have reviewed evidence of use; one study supplies the displayed numeric profile. DOI aliases are deduplicated; these are reporting-study counts, not proof of independent origins.

This is a presentation update. Analytical rules, approvals and dataset bindings are unchanged. See [handoff guide](../README.md) for execution limits and [manifest](manifest.json) for provenance. Earlier versions remain preserved.
