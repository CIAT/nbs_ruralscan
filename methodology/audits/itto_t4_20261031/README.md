## Source scope and three T4 assessments

ITTO's scope includes ecological restoration, production forestry, secondary forests,
agroforestry and agricultural mosaics. Those are not all assigned to active planting.
Only the explicit planted-forest non-conversion statement is admitted to this family.

- **Variable use:** named native habitat categories constrain planting choices in guidance;
  no suitability model or source-specific weights are supplied.
- **Direction:** categorical non-conversion; scalar direction remains `unclear` because
  land cover has no increasing/decreasing numeric ordering.
- **Calibration:** no scores, numerical endpoints or EO crosswalk. Native habitat identity,
  historical land use and local mapping require review. Do not equate all mapped grassland
  with native grassland or use this as a reason to exclude restoration of degraded native
  wetland forests.

Approval would retain the source safeguard for its stated context. It would not authorize
an automatic mask, substitute a satellite class for native-ecosystem identity, approve
plantation expansion, or decide the other forest-restoration families' applicability.
