## What went wrong most often

1. **A limit the source never set (23 suitability units).** The extractor put a hard
   minimum or maximum on a value where the paper only gave a score, a recommendation or a
   width. Reviewers removed all 23. Three forms:
   - the edge of a scored class read as a cutoff (11): e.g. Krois rates slopes above 30° as
     *highly suitable*, yet 30° was stored as the maximum; Brouwer's 160 cm ends the
     *marginal* class; Russell's "low priority" read as "excluded";
   - a recommended or commonly used range read as hard limits (8): FAO and WOCAT "can be
     used under these conditions", "commonly 1–5%", "as low as 150 mm";
   - a buffer width or study window read as a distance-to-water limit (4): "50 m of reserve
     on each side", "we set a maximum buffer width of 210 m".
   Pete confirmed 5 of these himself; the other 18 came from the 9 November AI source checks.
2. **Hazard intensity not logged (48 units).** Already ruled on 6 November (rule #56); the
   orchestrator backfilled it. No new rule needed.
3. **Strength read from the strongest number (20 units).** Already ruled on 6 November
   (rule #57: a range is classed by its weaker end; one plot per farm with no statistics
   is capped at moderate). No new rule needed.
4. **The same data counted more than once (6 effect units).** Five returns from one
   simulation, a season summary beside per-technique rows, a projection from the same plots
   as a measurement. Pete collapsed or dropped them. Not yet in the catalogue.
5. **A second-hand claim the cited original does not make (8 units).** 5 dropped or
   re-pointed by Pete, 3 replaced by their primary. Already covered (rules #25, #32).
6. **AI corrections introduced numbers not in the quote (11 units).** The 9 November source
   checks rewrote descriptions with weights from another table, citation years and "flat"
   turned into 0. These 11 units now fail the number check; they explain most of the rise in
   the number-provenance rate (4.7% to 5.0%).

The rest were one-off rulings with no recurring pattern: significance at exactly p = .05
(6), implied counterfactual for recharge (5), existing forest or natural marsh rather than
an NbS (5), ex-ante modelled benefit-cost ratios (3, already rule #23), bundled practices (2),
single routing or direction calls (7), lineage made specific (3), one #57 cap applied by the
orchestrator (1) and one open query (1). Peter's 29 "keep with stated limits" approvals
confirm evidence rather than report defects.

## What was changed to stop it

| Change | Where |
|---|---|
| Rule #59: a hard limit needs the source to say land past it is excluded or unsuitable | defect catalogue |
| Rule #60: buffer and reserve widths and study windows are design geometry, not distance limits | defect catalogue |
| Rule #61: one dataset gives one effect unit | defect catalogue |
| Rule #62: a correction must pass the number check like a new unit | defect catalogue |
| New advisory checks `ranked_class_limit`, `recommended_range_limit`, `design_geometry_limit` | `check_scope.py` (never auto-quarantined) |
| Regression test built from the original Krois, Russell, Negarim and Zhao rows | `tests/test_check_scope.py` |
| Ruleset v1.10.1, snapshot, intake allow-list | `RULESET_VERSIONS.md`, `_versions/v1.10.1/`, `evidence_intake.py` |

Rules #61 and #62 have no new check: #62 is already caught by `check_numbers`, and
#61 needs a judgement about which data overlap.

## How well the new checks work

- Run on the original versions of the 23 corrected units, they flag **20** (misses:
  Chen 2017 and two Critchley slope rows, whose quotes contain exclusion words for other
  conditions).
- On the current register they flag **47** active, unreviewed suitability units for a
  reviewer to look at: 39 recommended ranges stored as limits (mostly FAO Critchley and
  WOCAT rainfall and slope rows, siblings of units already corrected), 4 buffer widths, 4 ranked
  class edges. None are dropped automatically.
