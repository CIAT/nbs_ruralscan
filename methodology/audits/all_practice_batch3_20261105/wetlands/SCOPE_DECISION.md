## Existing definitions

- `wetland_management__constructed`: FAM `constructed_treatment_wetland` = “Engineered wetland for point-source / agricultural-drainage treatment (e.g. HSSF-CW).” Dominant limiter: “point-source / ag-drainage load + engineered siting (area, slope, inflow)”. Parked because treatment/engineering siting problem.
- `wetland_management__creation`: FAM `wetland_creation` = “Create a new wetland where none currently exists (water storage, habitat, nutrient interception).” `wetland_reconstruction` = “Reconstruct/engineer a wetland form on non-wetland land.” Limiter terrain/water availability/soil/currently-not-wetland.
- `wetland_management__restoration_rewetting` restores former degraded/drained wetland hydrology. Paper discusses historical floodplain loss, but sampled interventions are newly excavated lagoons and improve drainage of neighbouring cropland. It does not establish a degraded-wetland restoration footprint for each lagoon.

## Choice and implications

**Keep existing constructed routing:** all source evidence remains parked/M6; no new T3/T6 generated coverage. Appropriate if project's scope treats these arterial-drainage-plus-lagoon works as engineered infrastructure regardless of ecological functions. Retain finance/effect pointers and explicit gap.

**Approve bounded source routing to existing creation family:** represents rural excavated freshwater lagoons for water storage/flow regulation/habitat using existing FAM definition, without un-parking constructed treatment or tidal families. Then review candidate finance/effect claims under creation scope. Preserve bundled drainage/spoil-elevation intervention, sugarcane host limits and uncertain prior lagoon footprint. Does not license T4 thresholds, generic wetland restoration effects, nutrient-removal benefits, or new families.

Suggested interpretation for review: creation appears closer to described purpose than treatment. Requires explicit source-scope decision; no change implemented. Neither option merges/removes practices. Tidal/salt-marsh stays parked.
